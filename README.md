## 课程修读与经验总结

### 1. 教师风格与考勤
- 张琴老师上课非常认真负责；
- **教室上课**：一般不需要线上签到，张老师会直接把全班每位同学的座位提前排好，按固定座位就坐，来没来一目了然；全班 4 人一组，平时会有小组作业和课堂互动；
- **实验室实验**：在物流工程学院 123 实验室上课（大一《自动化专业导论》时曾参观过该实验室，大三下开始正式进实验室做实践）。实验课每节课都要签到，并要交实验报告。

### 2. 实验环节
- 实验主要是做**液位调节控制**；
- 如果想认真做的话实验耗时较多；
- 实验台位液位接线刚开始觉得有点困难，需要仔细对照原理接线，熟悉之后流程比较清晰。

### 3. 课后作业与特色任务
- **课后作业**：每节课都有作业发在课程群里，由于部分作业时间久已遗失，本仓库尽可能整理收录了完整的课后作业手写扫描件与原题解析图解；
- **拍“蛟龙号”视频**：课程有一个固定任务，4 人小组每年都要求拍一段“蛟龙号”相关视频。

### 4. 考试与复习建议
- **考试难度偏低**：考试基本偏向原题或者稍微修改一点数字的题目；
- **两门课协同复习**：考试内容和另一门《计算机控制系统》有非常多相似之处，大三下两门控制课完全可以一起复习；
- **概念为主**：概念题偏多，实际计算量偏少，带普通计算器即可完成；考前只要认真刷题几天就足够掌握通过。
